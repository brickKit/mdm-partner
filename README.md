# mdm-partner

组件 `mdm/partner`（业务伙伴；原 `mdm/customer`，D20）的仓库。旧版本（2.x，组件 ID 为 `mdm/customer`）在分支 `legacy/v2`，标签保留；本主分支按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

设计依据：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的边界卡 `docs/zh/07-components/mdm.md`（`mdm/partner` 一节）。代码随重建逐步加入。
